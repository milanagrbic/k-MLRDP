In the Excel table named ResultsIndividualRuns, results on the sample of instances used in the pre-experimental testing are presented.

Results for all individual runs of the Genetic Algorithm (GA), where the perturbation set is sampled randomly, are presented in the sheet RandomInitialization. Results for all individual runs of the GA, where the perturbation set is sampled using the neighborhood-based sampling strategy, are presented in the sheet NeighborhoodBasedInitialization.

The percentage of successful searches for both initialization strategies in each run is presented in the sheet named SuccessRateComparison.

The average search time per generation for both initialization strategies in each run is presented in the sheet named TimeComparison.

Results averaged across four runs for both initialization strategies are presented in the Excel table named ResultsAveraged.
