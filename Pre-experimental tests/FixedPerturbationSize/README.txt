In the Excel table named ResultsAveraged, results on the sample of instances used in the pre-experimental testing are presented, averaged across 4 independent runs of the Genetic Algorithm (GA).

In the sheet named ResultsDynamicPerturbation, the results obtained when the GA is executed using the dynamic perturbation change strategy are presented.

In the sheets Results100, Results1000, and ResultsPPI, results are presented for a sample of small RandomER instances with 100 nodes, medium-sized RandomER instances with 1000 nodes, and PPI instances, respectively. The column Perturbation size (percent) indicates the size of the perturbation set expressed as a percentage of the total number of nodes.

In these sheets, cells highlighted in green indicate that the dynamic perturbation change strategy achieved a better best objective function value than the fixed-size perturbation approach. Cells highlighted in yellow indicate that both approaches achieved the same best objective function value, while cells highlighted in red indicate that the fixed-size perturbation approach achieved a better best objective function value than the dynamic perturbation change strategy.
